Universal DLSS 5 Installer - Full Changelog
===============================================
Current Release: v1.12

======================================================================
UNIVERSAL DLSS 5 INSTALLER v1.12
======================================================================

- Added automatic Watch Dogs compatibility cleanup after FeedKit installs.
- Automatically disables RenoDX Upgrade for Watch Dogs to prevent the
  Disrupt_b64.dll startup crash.
- Automatically disables the standalone DX11 bridge for Watch Dogs because
  DLSS5-Feeder supplies the synthetic DLSS path for games without native DLSS.
- Enables the feeder, sets a 10-second creation delay, and removes duplicate
  feed configuration keys.
- Preserves disabled add-ons as recoverable .off files.

======================================================================
UNIVERSAL DLSS 5 INSTALLER v1.11
======================================================================

- Added a Run game button beside Re-detect in the Game section.
- The button launches the exact selected game executable.
- The selected game's directory is used as the launch working directory.
- The button stays disabled until a valid executable is selected.
- Launch results and errors are written to the debug log.

======================================================================
UNIVERSAL DLSS 5 INSTALLER v1.1
======================================================================

- Added a Purple appearance theme alongside Dark and Light.
- Added a Check for updates button backed by GitHub Releases.
- Added semantic version comparison and setup-EXE download/launch flow.
- Added graceful handling for repositories that have tags but no published Release.
- Added a Windows GitHub push helper that also works from an extracted project folder.
- Preserved the v1.0 SR2 Neural Rendering feature baseline.

This changelog reconstructs the full development history leading to the current v1.0 release.
Early builds were experimental development branches rather than formal public releases.

PRE-RELEASE DEVELOPMENT HISTORY
===============================

L.A. Noire DLSS5 Organizer
--------------------------
- First game-specific utility that evolved into the Universal Installer.
- Organized DLSS5-Feeder, ReShade, iMMERSE, RenoDX and NGX files into expected game directories.
- Checked for required files before reporting the installation ready.
- Originally used an iMMERSE/LaunchPad-style setup.

L.A. Noire DLSS5 Organizer v2
-----------------------------
- Reworked the 32-bit DLSS5 layout.
- Added separate host64 installation.
- Added installation of:
  - dlss5-feed.addon32
  - reshade-shaders\Shaders\DLSS5_Feed.fx
  - motion-estimation shaders
  - host64\dlss5-feed-host64.exe
  - host64\renodx-dlss5.addon64
  - host64\nvngx_dlssnr.dll
  - host64\nvngx_dlss.dll
- Added automatic validation of game-side and host-side files.
- Removed reliance on the old LaunchPad arrangement for newer feeder layouts.

L.A. Noire DLSS5 Auto Installer
-------------------------------
- Moved from file organization to automatic downloading.
- Added detection of LANoire.exe.
- Added automatic DLSS5-Feeder GitHub release retrieval.
- Added ReshadeMotionEstimation download.
- Added RenoDX DLSS5 package retrieval.
- Added automatic extraction/copying.
- Added backup-before-replacement behavior.
- Added automatic download of ReShade 6.8.0 Full Add-on.

L.A. Noire DLSS5 Auto Installer v3
----------------------------------
- Continued hardening of the automatic installer.
- Improved download/install handling and error recovery.
- Became the basis for moving away from a single-game installer.

Universal DLSS5 Installer - API Select
--------------------------------------
- First genuinely universal branch.
- Added renderer/API selection instead of assuming one game configuration.
- Began separating game detection from DLSS installation logic.
- Established the universal installer concept instead of maintaining separate BAT installers.

Universal DLSS5 Installer - Profile Aware v2
--------------------------------------------
- Added executable selection.
- Added architecture detection.
- Added game/profile detection.
- Added ReShade proxy selection.
- Added launcher/bootstrap detection warnings.
- Added nearby executable scanning.
- Added ability to change the selected DirectX API.
- Added automatic administrator elevation before modifying game files.
- Added FeedKit retrieval from GitHub.
- Added profile-screen reporting for:
  - executable
  - folder
  - API
  - architecture
  - profile
  - ReShade proxy

v4.3.8 - Saints Row 2 Crash Isolation
-------------------------------------
- Added a dedicated SR2 troubleshooting framework.
- Added staged component-disable testing.
- Tested disabling:
  - shaders
  - ReShade
  - dgVoodoo
- Identified repeated crash around:
  SR2_pc.exe +0x5EE9F2
- Determined that disabling dgVoodoo stopped the crash.
- This changed the SR2 strategy away from dgVoodoo.

v4.3.8 - SR2 Safe dgVoodoo / Auto Rollback
-------------------------------------------
- Added three conservative dgVoodoo compatibility profiles.
- Added safer GPU/VRAM settings.
- Added automatic launch testing.
- Added known-crash signature monitoring.
- Added automatic rollback after crash detection.
- All tested profiles still crashed.
- dgVoodoo was rejected for Saints Row 2.

v4.3.8 - SR2 DXVK Experimental
------------------------------
- Replaced:
  D3D9 -> dgVoodoo -> D3D11
  with:
  D3D9 -> DXVK x86 -> Vulkan
- Used DXVK 2.4 x32.
- Saints Row 2 successfully launched and ran through DXVK.
- Established DXVK as the validated translation layer for SR2.

v4.3.8 - SR2 DXVK Default
-------------------------
- Promoted DXVK from experiment to preferred SR2 translation path.
- SR2-specific handling deliberately avoided dgVoodoo.
- Established intended SR2 renderer path:
  SR2 D3D9 -> DXVK x86 -> Vulkan

v4.3.8 - SR2 Vulkan32 Neural Rendering Beta
-------------------------------------------
- Added experimental 32-bit Vulkan DLSS5 transport.
- Established architecture:
  SR2
  -> D3D9
  -> DXVK x86
  -> Vulkan
  -> ReShade 32-bit Vulkan
  -> DLSS5 Feed 32-bit
  -> 64-bit host
- First attempt at DLSS 5 Neural Rendering in a 32-bit DirectX 9 title.

v4.3.8 - Vulkan32 Host Fix
--------------------------
- Fixed PowerShell variable collision where $host conflicted with built-in $Host.
- Changed the host executable variable to a safe name such as $hostExe.
- Allowed the 64-bit feeder host to launch correctly.

v4.3.8 - Vulkan32 ReShade Choice
--------------------------------
- Added explicit handling for the required ReShade build.
- Established that the Full Add-on build was needed for the DLSS5 feeder.
- Important for x86 titles.

----------------------------
- Added/repaired:
  reshade-shaders\Shaders\DLSS5_Feed.fx
- Corrected ReShade shader search paths.
- Resolved cases where ReShade loaded but DLSS5 Feed did not compile or appear.

v4.3.8 - Vulkan32 Feed Core Fix
-------------------------------

v4.3.8 - SR2 Mode 1 Transport Validation
----------------------------------------
- Added dedicated transport-test mode.

- Validated:

v4.3.8 - SR2 Mode 2 Neural Rendering
------------------------------------
- Added real Neural Rendering mode.
- Successful runtime verification established:
  - Vulkan frames delivered

  - NGX Feature 18 created
  - inline Feature 18 evaluation succeeded
- First confirmed end-to-end SR2 pipeline:
  D3D9
  -> DXVK x86

v4.3.8 - SR2 Neural Rendering Settings UI
-----------------------------------------
This became the branch later selected as the official release baseline.

Added awareness of the real DLSS5 Feed host-settings interface, including:
- Enable Neural Rendering
- Enable Upscaling
- NR Preset
- NR Style
- NR Intensity
- Local Tone Strength
- Local Structure Strength
- Skin Structure Strength
- Automatic Mask
- UI Correction
- Paper White Scale
- HDR Transfer Strength
- Color Strength
- motion-vector/depth controls

Established the correct workflow:
- change settings inside DLSS 5 Feed
- Apply to the DLSS 5 host
- optionally Reload from host

Corrected the earlier assumption that these settings belonged exclusively in ReShade's Add-ons page.

IMPORTANT RELEASE DECISION
--------------------------
The SR2 Neural Rendering Settings UI branch was explicitly selected as the branch to preserve.

Everything after this point from the experimental Natural Pipeline branch was excluded from the official release line.

- renderer detection
- game/profile detection

- Install / Verify / Repair functionality

- DLSS5 feeder installation framework

- 64-bit host architecture
- SR2-specific Neural Rendering tooling
